# DreamWaQ: 隐式地形想象

训练能够在没有明确地形感知的情况下穿越复杂地形的盲态行走策略一直是足式机器人领域的长期挑战。虽然教师-学生框架和显式估计器等方法在训练期间依赖特权地形信息，但它们需要额外的机制来处理地形感知行为的仿真到现实迁移。DreamWaQ 采用不同的方法，通过混合变分自编码器架构将隐式地形表示与显式状态估计相结合。

## DreamWaQ 框架

DreamWaQ 的核心见解是地形信息可以隐式编码在观察历史中，设计良好的编码器可以从该历史中提取隐式地形表示和显式状态估计。DreamWaQ 不是单独训练历史编码器来模仿特权编码器（如教师-学生框架那样），而是使用一个变分自编码器（VAE）来联合学习：

1. **估计显式状态**，如基座线速度、足部接触状态和足部高度信息
2. **将隐式地形信息编码**到捕获地形几何和属性的潜在向量中
3. **重构未来状态**以确保学习到的表示具有预测性和意义

混合架构由两部分组成：**隐式编码器**输出代表地形信息的潜在向量，**显式估计器**输出包含直接可解释状态估计的向量。两者都通过监督学习联合训练，而策略则通过强化学习训练。

## 实现

DreamWaQ 通过三个核心组件实现：用于编码的 VAE 模块、演员-评论家架构和专门的 PPO 算法。VAE 是方法的核心，将观察历史编码为有意义的表示。

### 变分自编码器（VAE）

VAE 将观察历史编码为两个不同的输出：潜在向量（隐式地形表示）和显式向量（状态估计）。编码器架构使用具有重参数化的多层感知机进行采样。

VAE 编码器结构由多个带激活函数的线性层组成。最终层输出潜在维度和显式维度（每个都有均值和方差），实现训练期间的概率采样。

VAE 输出隐式和显式变量的分布参数，实现训练期间的采样和部署期间的均值推理。前向方法将观察历史编码为分布参数，使用重参数化技巧从这些分布中采样，并返回样本和参数。在推理期间，使用均值进行确定性输出。

### 演员-评论家架构

DreamWaQ 的演员-评论家扩展了标准架构以整合 VAE 输出。演员接收当前观察和编码历史（隐式加显式），而评论家使用具有真实地形数据的特权观察。

演员输入维度组合了观察值、显式状态估计和潜在维度。评论家使用特权观察，可能包括地形高度测量、接触状态和其他仿真特定的信息。VAE 使用历史输入大小、潜在维度、显式维度和解码器输出大小进行初始化。

在动作采样期间，VAE 通过从学习到的分布中采样将历史编码为潜在变量。这些潜在变量与当前观察连接，输入演员网络以产生动作分布。

### 带有 DreamWaQ 的 PPO

训练算法通过监督学习将标准 PPO 更新与 VAE 训练相结合。VAE 通过三个目标进行训练：

1. **显式估计损失**：预测与真实显式状态之间的均方误差（速度、接触、足部高度）
2. **重构损失**：解码的下一状态与实际下一状态之间的均方误差
3. **KL 散度损失**：正则化以保持潜在分布接近标准正态分布

显式估计损失使用预测的显式状态与真实标签之间的均方误差，由终止标志掩码以忽略已完成的回合。重构损失类似地使用解码器输出与下一状态之间的均方误差，也由终止标志掩码。KL 散度损失将潜在分布正则化到标准正态分布，以确保有意义的潜在表示。

完整的 VAE 损失将所有三个项与 KL 散度项的可配置权重相结合。总损失等于显式估计损失加上重构损失加上加权 KL 散度损失。

完整的更新过程在 PPO 梯度步和 VAE 梯度步之间交替。首先，计算 PPO 损失并通过策略和价值网络反向传播。然后，VAE 经历多轮梯度更新以最小化 VAE 损失组件。

## 配置参数

DreamWaQ 引入了特定于 VAE 架构和训练过程的多个配置参数。这些参数在环境和算法配置中定义。

### 环境配置

| 参数 | 类型 | 默认值 | 描述 |
|-----------|------|---------|-------------|
| frame_stack | int | 5 | 历史编码器输入的观察帧堆叠数量 |
| num_history_obs | int | 225 | 堆叠观察的总维度 |
| num_latent_dims | int | 16 | 隐式地形潜在向量维度 |
| num_explicit_dims | int | 24 | 显式状态估计维度 |
| num_decoder_output | int | 45 | 解码器输出维度（下一状态预测） |
| c_frame_stack | int | 5 | 评论家观察的帧堆叠大小 |
| num_privileged_obs | int | 计算得出 | 总特权观察维度 |

### 策略配置

| 参数 | 类型 | 默认值 | 描述 |
|-----------|------|---------|-------------|
| encoder_hidden_dims | list | [256, 128] | VAE 编码器的隐藏层维度 |
| decoder_hidden_dims | list | [256, 128] | VAE 解码器的隐藏层维度 |
| critic_hidden_dims | list | [1024, 256, 128] | 评论家网络的隐藏层维度 |

### 算法配置

| 参数 | 类型 | 默认值 | 描述 |
|-----------|------|---------|-------------|
| encoder_lr | float | 2.0e-4 | VAE 编码器/解码器的学习率 |
| num_encoder_epochs | int | 1 | 每次 PPO 更新 VAE 的梯度步数 |
| vae_kld_weight | float | 2.0 | VAE 目标中 KL 散度损失的权重 |

### 运行器配置

| 参数 | 类型 | 默认值 | 描述 |
|-----------|------|---------|-------------|
| policy_class_name | str | ActorCriticDreamWaQ | DreamWaQ 的策略类 |
| algorithm_class_name | str | PPO_DreamWaQ | DreamWaQ 的算法类 |
| runner_class_name | str | DreamWaQRunner | DreamWaQ 的运行器类 |

## 训练工作流程

训练 DreamWaQ 策略遵循标准的 legged_gym 工作流程，具有任务特定的配置。

### 基础训练

要在 Go2 机器人上训练 DreamWaQ 策略，使用以下命令：

```bash
python -m legged_gym.scripts.train --task=go2_dreamwaq --headless
```

这将使用 go2_dreamwaq_config.py 中定义的默认配置开始训练。训练过程将记录进度到 TensorBoard 并定期保存检查点。

### 配置自定义

你可以通过修改配置文件或传递命令行参数来自定义训练。需要调整的关键参数包括：

- num_latent_dims：控制隐式地形表示的容量
- num_explicit_dims：确定估计哪些显式状态
- vae_kld_weight：平衡重构质量与潜在正则化
- encoder_lr：VAE 的学习率（通常需要低于策略学习率）

### 监控训练

训练期间记录以下指标：

- 总奖励和单个奖励组件
- 价值损失和替代损失（PPO 指标）
- 显式估计损失（VAE 显式预测准确性）
- 重构损失（VAE 下一状态预测准确性）
- KL 散度损失（VAE 潜在正则化）

这些指标有助于诊断训练问题。高 KL 散度可能表明潜在空间正则化不佳。高重构损失表明 VAE 难以预测未来状态。高显式估计损失意味着显式状态预测不准确。

## 与标准 PPO 的区别

DreamWaQ 扩展了标准 PPO，具有几个关键差异，实现了隐式地形想象：

### 架构差异

1. **VAE 模块**：DreamWaQ 添加了一个变分自编码器，将观察历史编码为潜在表示。这是无需显式地形感知实现地形想象的核心创新。

2. **双输出编码器**：与输出单一表示的标准编码器不同，DreamWaQ VAE 同时输出隐式（潜在）和显式（可解释）表示。

3. **扩展的演员输入**：演员网络不仅接收当前观察，还接收编码历史（隐式和显式组件），实现上下文感知动作选择。

### 训练差异

1. **监督学习组件**：DreamWaQ 为 VAE 添加了监督学习目标以及标准 RL 目标。VAE 通过监督损失学习预测显式状态和重构未来状态。

2. **多个优化器**：标准 PPO 对所有参数使用单一优化器。DreamWaQ 对 RL 参数（策略和价值）和 VAE 参数使用单独的优化器，允许不同的学习率和更新频率。

3. **额外的损失项**：训练目标包括三个 VAE 特定损失（显式估计、重构、KL 散度）以及标准 PPO 损失（替代、价值、熵）。

### 观察差异

1. **历史缓冲区**：DreamWaQ 维护一个过去观察的缓冲区（obs_history），输入 VAE。这些时间信息对于推断地形属性至关重要。

2. **显式标签**：环境计算显式标签目标（基座速度、接触状态、足部高度），在训练期间监督显式估计器。

3. **下一状态预测**：VAE 解码器学习预测下一观察状态，需要环境为训练提供 next_state_buf。

## 推理和部署

训练完成后，DreamWaQ 策略可以在仿真和真实机器人上部署用于推理。

### 运行训练好的策略

要运行训练好的策略，使用 play 脚本：

```bash
python -m legged_gym.scripts.play --task=go2_dreamwaq --load_run=session_name
```

这将加载训练好的检查点并在仿真环境中运行策略。

### 导出到真实机器人

DreamWaQ 策略可以导出用于真实机器人部署。在推理期间，VAE 使用确定性均值而不是采样，提供一致的行为。必须在真实机器人上维护观察历史缓冲区以输入 VAE 编码器。

要导出训练好的策略：

```bash
python -m legged_gym.scripts.play --task=go2_dreamwaq --export_policy
```

导出的策略将保存到日志目录，可以加载到真实机器人上进行部署。
